### 1. 新增的辅助函数（main.js）

- `getUISettingsFromLocalStorage()` - 获取 UI 面板组设置
- `getProjectAdjacentSettings()` - 获取项目旁设置
- `getCustomFolderSettings()` - 获取自定义文件夹设置

{

    aeTheme: "dark",                 // ✅ 新增
    projectAdjacentSettings: {...},  // ✅ 新增
    customFolderSettings: {...},     // ✅ 新增

### 3. 修改的 loadPresetsFromDisk() 函数

现在会恢复所有新增的配置项，并在日志中显示恢复状态。

- ✅ 切换 UI 面板组设置（显示/隐藏按钮）

## 测试步骤

### 测试 1：UI 面板组设置保存和恢复

1. **设置 UI 面板组**
   - 打开扩展
   - 点击设置按钮，进入 UI 设置区域
   - 切换几个 UI 元素的显示/隐藏（如：隐藏主题按钮、隐藏语言按钮）
   - 观察日志：应该看到 `[UI Settings] 设置已保存`

2. **检查预设文件**
   - 点击"打开预设目录"按钮
   - 打开 `Eagle2Ae-Presets.json` 文件
   - 确认文件中包含 `uiSettings` 字段：
     ```json
     {
       "uiSettings": {
         "theme": false,
         "language": false,
         "log": true,
         "projectInfo": true,
         "logPanel": true,
         "header": true,
         "fullscreen": false
       }
     }
     ```

3. **测试恢复**
   - 点击"重置默认"按钮（会重置所有设置）
   - 关闭并重新打开扩展
   - 观察日志：应该看到 `✅ 已恢复 UI 面板组设置`
   - 确认 UI 元素的显示状态恢复到之前的设置

### 常见问题排查

#### 问题 1：预设文件中没有新增字段

**可能原因：**
- 修改后没有触发保存
- 缓存问题

**解决方法：**
- 手动修改一个设置，触发自动保存
- 或点击"重置默认"按钮，强制保存

#### 问题 2：恢复时没有应用设置

**可能原因：**
- 预设文件格式错误
- localStorage 权限问题

**解决方法：**
- 检查预设文件是否是有效的 JSON
- 检查浏览器控制台是否有错误
- 检查日志面板的错误消息

#### 问题 3：自动保存不工作

**可能原因：**
- `window.eagleToAeApp` 未初始化
- 函数调用时机问题

**解决方法：**
- 检查控制台是否有 JavaScript 错误
- 确认 `main.js` 已正确加载
- 手动调用 `window.eagleToAeApp.savePresetsSilently()` 测试
