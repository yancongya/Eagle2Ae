# 交互动画

## 鼠标交互动画

### 悬停效果
- **按钮悬停**: 按钮悬停时的颜色、尺寸变化效果
- **卡片悬停**: 卡片悬停时的上浮、阴影效果
- **导航项悬停**: 导航菜单项的悬停反馈

### 点击反馈
- **按钮点击**: 点击时的按下效果
- **加载状态**: 操作执行时的加载反馈
- **成功/失败反馈**: 操作结果的视觉反馈

## 拖拽交互动画

### DragToTop 组件动画
- **拖拽轨迹**: 显示拖拽过程中的轨迹线
- **视觉反馈**: 拖拽过程中的视觉元素反馈
- **物理效果**: 基于 Matter.js 的物理动画效果

### 过滤拖拽距离
- **阈值设定**: 设定触发动画的最小拖拽距离
- **距离反馈**: 根据拖拽距离调整视觉反馈强度
- **角度旋转**: 根据拖拽方向调整元素角度

## 触摸交互动画

### 移动端交互
- **触摸反馈**: 移动端触摸操作的视觉反馈
- **滑动动画**: 滑动操作的平滑动画效果
- **缩放动画**: 双指缩放的动画效果

## 组件级交互动画

### UI 组件动画
- **开关切换**: Switch/Toggle 组件的切换动画
- **下拉菜单**: 下拉菜单的展开/收起动画
- **模态框**: 模态框的显示/隐藏动画

## 状态变化动画

### 数据驱动动画
- **列表更新**: 列表项增删改的过渡动画
- **表单验证**: 表单验证状态的视觉反馈
- **进度指示**: 操作进度的动画指示

## 性能考虑

### 优化策略
- **使用 transform 和 opacity**: 避免触发布局重排
- **防抖处理**: 交互事件的防抖和节流
- **硬件加速**: 启用硬件加速优化性能
