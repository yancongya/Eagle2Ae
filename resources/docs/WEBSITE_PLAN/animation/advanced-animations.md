# 高级动画与物理效果

## 彩带效果系统

### ConfettiCannon 类
`src/utils/ConfettiCannon.js` 实现了一个高级的彩带效果系统，使用了多个 GSAP 插件：

- **Observer**: 处理拖拽事件检测
- **Physics2DPlugin**: 实现物理效果，如重力、速度、角度
- **ScrollTrigger**: 控制动画触发
- **CustomEase**: 自定义缓动函数
- **CustomWiggle**: 创建波浪效果

### 功能特性
- **拖拽绘制**: 用户可以在页面上拖拽创建线条
- **物理爆炸**: 拖拽结束后创建基于物理的彩带爆炸效果
- **图像克隆**: 从预加载的图像库中随机选择图像作为彩带
- **动态缩放**: 根据拖拽距离动态调整起始图像的大小
- **自动滚动**: 爆炸结束后自动滚动到页面顶部

### 配置与预加载
- **图像库**: 预加载多种 2D 和 3D 形状图像
- **配置驱动**: 支持动态配置图像和效果参数
- **性能优化**: 支持用户减少动画偏好的检测

## 自定义延迟光标

### 实现机制
`src/utils/CustomCursor.js` 实现了一个非侵入式的延迟光标系统：

```javascript
// 通过 CSS 变量存储延迟后的光标位置
const setMX = (v) => document.documentElement.style.setProperty('--e2a-mx', v + 'px');
const setMY = (v) => document.documentElement.style.setProperty('--e2a-my', v + 'px');
```

### 核心功能
- **非侵入式**: 不替换系统光标，不创建可视叠加层
- **阻尼效果**: 使用 GSAP 的 quickTo 实现平滑的阻尼效果
- **CSS 变量**: 通过 CSS 变量将延迟后的坐标传递给页面
- **自适应**: 根据用户的减少动画偏好自动调整
- **内存管理**: 提供清理函数以避免内存泄漏

### 使用场景
- 用于需要获取平滑光标位置的动画效果
- 为自定义动画提供延迟的光标位置
- 遫焰跟随效果或其他光标交互效果

## 主题注入系统

### 动态主题管理
`src/utils/injectIframeLightTheme.js` 实现了动态的 iframe 主题管理系统：

```javascript
// 为 iframe 注入亮色主题
export function injectLightThemeIntoIframe(iframe) {
  // 注入 CSS 规则
  // 添加 theme-light 类
  // 移除 dark 类
}
```

### 功能特性
- **CSS 规则注入**: 为 iframe 内容注入完整的亮色主题 CSS
- **类名管理**: 动态添加/移除主题相关的 CSS 类
- **错误处理**: 妥善处理跨域和加载错误
- **细粒度控制**: 针对不同 UI 元素的专门样式规则
- **可逆操作**: 提供移除主题的方法

### 应用场景
- 预览页面需要在暗色模式下显示亮色扩展示例
- 为嵌入的第三方内容强制应用特定主题
- 在暗色模式下预览亮色界面

## Splitpanes 预览系统

### 多窗格布局
- **响应式布局**: 移动端单窗格，桌面端三窗格
- **可调整大小**: 用户可以拖拽调整窗格大小
- **嵌套布局**: 使用水平和垂直分割创建复杂的布局
- **主题适配**: 预览窗格的主题会响应页面主题变化

### 主题同步实现
在预览页面实现了暗色/亮色模式的同步：
- **watch 机制**: 监听主题变化
- **动态应用**: 根据主题动态注入或移除主题样式
- **iframe 重载处理**: iframe 重新加载时重新应用主题
- **生命周期管理**: 组件卸载时清理事件监听器

## 动画系统集成

### GSAP 生态系统应用
项目广泛使用了 GSAP 的各种插件：

- **核心动画**: 基础的补间动画和时间轴
- **物理引擎**: Physics2DPlugin 实现真实的物理效果
- **观察器**: Observer 实现交互事件检测
- **滚动触发动画**: ScrollTrigger 实现滚动相关动画
- **自定义缓动**: CustomEase 和 CustomWiggle 创建特殊效果

### 性能优化
- **quickTo**: 用于高性能的数值更新
- **will-change**: 优化动画性能
- **requestAnimationFrame**: 确保流畅的动画执行
- **内存管理**: 组件卸载时清理动画实例
