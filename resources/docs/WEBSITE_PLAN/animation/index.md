# 动画系统

本目录包含 eagle2ae_web 项目的动画系统相关文档。

## 文件列表

- [**gsap-integration.md**](./gsap-integration.md) - GSAP 集成说明，GSAP 动画库集成
- [**scroll-animations.md**](./scroll-animations.md) - 滚动动画系统，滚动触发动画
- [**page-transitions.md**](./page-transitions.md) - 页面过渡动画，View Transitions API 和页面切换动画
- [**interactive-animations.md**](./interactive-animations.md) - 交互动画，用户交互动画
- [**advanced-animations.md**](./advanced-animations.md) - 高级动画与物理效果，彩带效果、自定义光标、主题注入

## 总览

这些文档全面介绍了项目的动画系统实现，包括 GSAP 集成、各类动画类型和性能优化策略。对于需要理解和修改项目动画效果的开发者非常有帮助。
