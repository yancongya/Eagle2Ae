# Hero 组件标题动画功能文档

## 功能概述

在 Hero 组件中添加了标题悬停动画功能。当用户将鼠标悬停在标题上时，"Eagle" 和 "AE" 文本会互相滚动切换，并在 2 秒后自动恢复原状。

## 功能实现

### 1. HTML 结构
- 将标题文本分割为多个部分，每个部分用 `<span class="title-part">` 包装
- 为标题添加鼠标事件监听器 (`@mouseenter`, `@mouseleave`)
- 添加 `cursor-pointer` 类以指示可交互性

### 2. 动画流程
- **悬停触发**：200ms 延迟后开始动画
- **Eagle 变 AE**：Eagle 部分向上移动并淡出，然后变为 AE 并向下移动淡入
- **AE 变 Eagle**：AE 部分向下移动并淡出，然后变为 Eagle 并向上移动淡入
- **自动恢复**：2 秒后自动恢复到原始文本状态

### 3. 技术实现
- 使用 GSAP 实现平滑动画效果
- 通过 `querySelector` 选择标题部分元素
- 使用 `textContent` 属性动态更改文本内容
- 使用 `y` 属性和 `opacity` 实现滚动和淡入淡出效果

### 4. 动画参数
- 动画持续时间：0.8 秒
- 缓动函数：`power2.inOut`
- 悬停响应延迟：200 毫秒
- 自动恢复延迟：2000 毫秒

## 用户体验

### 视觉效果
- 悬停时文本平滑滚动切换
- 动画效果流畅自然
- 2 秒后自动恢复避免干扰用户阅读

### 交互反馈
- 鼠标指针变为手型指示可交互
- 平滑的动画过渡效果
- 与现有页面动画风格保持一致

## 代码结构

### 事件处理
- `startTitleAnimation()`：处理悬停动画逻辑
- `resetTitleAnimation()`：处理恢复动画逻辑
- 使用 `setTimeout` 确保动画按预期时间执行

### 选择器使用
- 使用 `.title-part` 类选择所有标题部分
- 定位第 1 个和第 3 个元素进行文本交换（Eagle 和 AE 部分）

## 注意事项

- 确保初始页面加载动画完成后才响应悬停事件
- 避免连续快速悬停导致动画冲突
- 动画不应对可访问性造成负面影响

## 性能考虑

- 使用 requestAnimationFrame 优化动画性能
- 避免在动画过程中进行不必要的 DOM 操作
- 动画结束后正确清理状态
