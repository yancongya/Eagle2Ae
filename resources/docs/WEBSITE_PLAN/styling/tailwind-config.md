# Tailwind 配置

## 核心配置

### 配置文件结构
```javascript
// tailwind.config.js
module.exports = {
  content: [
    './index.html',
    './src/**/*.{vue,js,ts,jsx,tsx}',
  ],
  theme: {
    extend: {
      // 自定义扩展
    },
  },
  plugins: [
    // 自定义插件
  ],
}
```

## 主题配置

### 颜色系统
- **主色调**: 使用 indigo 作为主色调
- **辅助色**: 配置了完整的颜色系统
- **深色模式**: 适配深色模式的颜色变量

### 间距系统
- **基础单位**: 采用 4px 基础网格系统
- **比例关系**: 遵循设计系统的一致性

## 响应式设计

### 断点配置
- **sm**: 640px
- **md**: 768px  
- **lg**: 1024px
- **xl**: 1280px
- **2xl**: 1536px

## 自定义组件

### UI 组件
- **按钮样式**: 配置了多种按钮变体
- **卡片样式**: 定义了项目特有的卡片样式
- **表单元素**: 自定义表单元素样式

## 插件系统

### 第三方插件
- **自定义类名**: 扩展了特定的实用类
- **动画类**: 添加了自定义动画类

## 优化配置

### PurgeCSS
- **生产环境**: 自动移除未使用的 CSS
- **开发环境**: 保留所有类名便于开发

### 性能优化
- **精简配置**: 仅保留实际使用的功能
- **模块化**: 可按需加载特定功能模块
