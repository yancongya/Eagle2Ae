# 技术栈详解

## 核心框架

### Vue 3
- **版本**: 3.5.22+
- **特性**:
  - Composition API
  - 响应式系统
  - 单文件组件 (SFC)
  - Teleport, Suspense 等新特性
- **优势**:
  - 更好的逻辑组织
  - 更小的打包体积
  - 更好的 TypeScript 支持

### Vue Router 4
- **功能**:
  - 基于 Vue 3 的路由管理
  - 嵌套路由支持
  - 路由守卫
  - 滚动行为控制
- **特性**:
  - History 模式
  - 编程式导航
  - 路由参数和查询

## 构建工具

### Vite
- **版本**: 7.1.7+
- **优势**:
  - 快速的开发服务器启动
  - 按需编译
  - 热模块替换 (HMR)
  - 原生 ES 模块支持
- **配置**:
  - 自动化导入
  - 环境变量管理
  - 代理配置

### PostCSS
- **功能**:
  - CSS 预处理
  - 自动添加浏览器前缀
  - CSS 模块化支持

## 样式系统

### Tailwind CSS
- **版本**: 3.4.17+
- **特性**:
  - 实用优先的 CSS 框架
  - 响应式设计
  - 深色模式支持
  - 可自定义配置
- **优势**:
  - 快速 UI 开发
  - 一致的设计语言
  - 较小的 CSS 体积

## 动画系统

### GSAP (GreenSock Animation Platform)
- **版本**: 3.13.0+
- **核心插件**:
  - `gsap`: 核心动画面板
  - `ScrollTrigger`: 滚动触发动画
  - `ScrollToPlugin`: 平滑滚动
  - `CustomEase`: 自定义缓动函数
  - `Matter-js`: 2D 物理引擎 (用于特殊动画)
- **应用场景**:
  - 页面过渡动画
  - 滚动触发动画
  - 交互动画
  - 复杂物理效果

## UI 组件库

### Splitpanes
- **功能**: 可调整大小的窗格组件
- **应用场景**: 预览页面的多视图展示
- **特性**:
  - 双向调整
  - 保存布局状态
  - 响应式设计

### VueUse
- **版本**: 13.9.0+
- **功能**:
  - 实用的 Vue Composition 函数集合
  - 深色模式切换 (useDark)
  - 响应式工具
  - 实用工具函数

### Vue I18n
