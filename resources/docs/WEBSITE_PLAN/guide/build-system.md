# 构建系统配置

## Vite 配置

### 核心配置
- **开发服务器**: 支持热重载和快速启动
- **构建优化**: 自动代码分割和压缩
- **环境变量**: 支持不同环境的配置管理

### 插件系统
- **Vue 插件**: 支持单文件组件编译
- **CSS 预处理**: 集成 PostCSS 和 Tailwind
- **静态资源**: 自动优化图片和其他资源

## 构建流程

### 开发构建
- 快速冷启动
- 按需编译
- 热模块替换

### 生产构建
- 代码分割
- 自动压缩
- 资源优化

## 优化策略

### 性能优化
- Tree Shaking: 移除未使用代码
- 代码分割: 按路由和组件分割
- 预加载: 优化资源加载顺序

### 输出配置
- 资源哈希: 缓存优化
- 压缩: JS/CSS 压缩
- 体积分析: 构建结果分析
