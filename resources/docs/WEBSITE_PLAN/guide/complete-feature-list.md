# eagle2ae_web 完整功能清单

## 核心功能模块

### 1. 国际化系统 (i18n)
- **多语言支持**: 中文 (zh-CN) 和英文 (en-US)
- **动态语言切换**: 带动画的下拉语言切换器
- **View Transition**: 支持视图过渡动画的语言切换
- **本地存储**: 记住用户的语言偏好
- **动态配置**: 支持从外部 JSON 文件加载配置

### 2. 主题系统
- **深色/浅色模式**: 基于 `@vueuse/core` 的 `useDark` 实现
- **主题切换**: 全局主题切换功能
- **主题持久化**: 使用 localStorage 保存用户偏好
- **iframe 主题同步**: 为预览页面的 iframe 动态注入主题样式
- **CSS 变量**: 使用 CSS 变量实现主题定制

### 3. 路由与导航
- **Vue Router**: 基于 Vue Router 4 的路由管理
- **页面过渡**: 使用 View Transitions API 实现平滑页面切换
- **滚动行为**: 自定义的滚动行为控制
- **分页滚动**: 大屏幕上的分页滚动功能
- **响应式导航**: 桌面端和移动端的适应性导航

### 4. 动画系统
- **GSAP 集成**: 完整的 GSAP 动画库集成
- **ScrollTrigger**: 滚动触发动画
- **Physics2D**: 2D 物理引擎实现真实效果
- **CustomEase**: 自定义缓动函数
- **CustomWiggle**: 创建波浪和摆动效果
- **Observer**: 处理用户交互事件
- **高级效果**: 彩带效果、拖拽绘制、物理爆炸

### 5. UI 组件系统
- **组件化架构**: 高度模块化的组件设计
- **响应式设计**: 使用 Tailwind CSS 实现响应式布局
- **交互组件**: 拖拽返回顶部、语言切换器等高级交互组件
- **Splitpanes**: 多窗格预览布局
- **动画效果**: 组件级别的入场和退场动画

## 主要页面功能

### 1. 首页 (Home)
- **Hero 区域**: 带动画的主标题和功能卡片
- **功能详情**: 交错布局的功能详情展示
- **拖拽返回顶部**: 全页面拖拽返回顶部功能
- **自定义光标**: 延迟跟随效果的自定义光标
- **彩带效果**: 高级的彩带动画系统

### 2. AE 预览页面
- **多窗格布局**: 桌面端三窗格，移动端单窗格
- **iframe 预览**: 嵌入的 AE 扩展示例
- **主题同步**: 与主页面主题同步的预览效果
- **动画过渡**: 页面加载和切换动画

### 3. Eagle 预览页面
- **多窗格布局**: 与 AE 预览页面相同的布局
- **iframe 预览**: 嵌入的 Eagle 扩展示例
- **主题同步**: 与主页面主题同步的预览效果
- **动画过渡**: 页面加载和切换动画

### 4. 下载页面
- **平台切换**: AE 和 Eagle 扩展的切换面板
- **动态配置**: 从 JSON 文件加载下载配置
- **多协议支持**: 支持网页链接、自定义协议、下载等多种方式
- **动画效果**: 平滑的切换动画和悬停效果
- **国际化**: 完整的多语言支持

### 5. 关于页面
- **社交链接**: 动态加载的社交链接配置
- **动画效果**: 页面元素的入场动画
- **国际化**: 完整的多语言支持
