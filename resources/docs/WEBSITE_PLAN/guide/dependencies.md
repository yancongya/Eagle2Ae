# 依赖包说明

## 核心依赖 (Production)

### Vue 生态系统
- **vue**: ^3.5.22
  - 核心框架
  - 响应式数据绑定
  - 组件系统
  - Composition API

- **vue-router**: ^4.5.1
  - 官方路由管理器
  - 嵌套路由支持
  - 路由守卫
  - 滚动行为控制

- **vue-i18n**: ^9.14.5
  - 国际化解决方案
  - 多语言支持
  - Composition API 集成
  - 消息格式化

### 动画库
- **gsap**: ^3.13.0
  - GreenSock 动画平台
  - 高性能动画引擎
  - 丰富的缓动函数
  - 插件系统 (ScrollTrigger, ScrollToPlugin, CustomEase)

- **matter-js**: ^0.20.0
  - 2D 物理引擎
  - 用于 DragToTop 组件的物理效果
  - 碰撞检测
  - 重力和弹跳效果

### UI 组件库
- **splitpanes**: ^4.0.4
  - 可调整大小的窗格组件
  - 用于预览页面的多视图展示
  - 响应式设计
  - 布局保存功能

- **swiper**: ^12.0.2
  - 触摸滑动库
  - 轮播图功能
  - 高性能滑动体验

### 实用工具库
- **@vueuse/core**: ^13.9.0
  - Vue 组合式工具库集合
  - useDark (深色模式)
  - 响应式工具函数
  - 实用程序函数

## 开发依赖 (Dev Dependencies)

### 构建工具
- **vite**: ^7.1.7
  - 下一代前端构建工具
  - 快速的冷启动
  - 热模块替换 (HMR)
  - 原生 ES 模块支持

- **@vitejs/plugin-vue**: ^6.0.1
  - Vue 3 支持插件
  - SFC 编译
  - 模板预编译

### CSS 工具
- **tailwindcss**: ^3.4.17
  - 实用优先的 CSS 框架
  - 响应式设计
  - 深色模式支持
  - 可自定义配置

- **postcss**: ^8.5.6
  - CSS 处理工具
  - 插件生态系统
  - 自动前缀添加

- **autoprefixer**: ^10.4.21
  - CSS 自动添加浏览器前缀
  - 基于 browserslist 配置
  - 确保浏览器兼容性

## 版本管理策略

### 版本更新原则
1. **主要版本** - 框架级升级，需全面测试兼容性
2. **次要版本** - 功能新增，保持向后兼容
3. **补丁版本** - 修复 bug，安全更新

### 依赖锁定
- 使用 pnpm 锁定依赖版本
- 定期检查安全漏洞
- 测试依赖更新的兼容性

## 性能影响分析

### 包大小影响
- **Vue 3**: 约 35KB (压缩后)
- **Vue Router**: 约 5KB (压缩后)
- **GSAP**: 约 30KB (完整版，可按需引入)
- **Tailwind CSS**: 可通过 PurgeCSS 优化

### 加载性能
- 启用代码分割和懒加载
- 按需引入 GSAP 插件
- 使用 Tree Shaking 移除未使用代码

## 安全考虑

### 依赖安全
- 定期运行 `pnpm audit` 检查漏洞
- 使用最新的稳定版本
- 监控安全公告

### 最佳实践
- 避免引入不必要的依赖
- 定期更新依赖包
- 使用 SRI (Subresource Integrity) 验证
