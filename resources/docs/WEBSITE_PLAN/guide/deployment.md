# 部署配置

## 部署环境

### 生产环境
- **静态服务器**: 支持 History 模式的静态文件服务器
- **CDN 配置**: 资源文件 CDN 加速配置
- **缓存策略**: 静态资源缓存头配置

### 预览环境
- **自动部署**: 提交代码后自动构建预览
- **环境隔离**: 开发、测试、生产环境分离

## 部署流程

### 构建步骤
```bash
# 1. 安装依赖
pnpm install

# 2. 构建生产版本
pnpm build

# 3. 部署到服务器
# (根据具体部署平台有所不同)
```

### 配置文件
- **vercel.json**: Vercel 部署配置
- **Dockerfile**: 容器化部署配置
- **nginx.conf**: Nginx 服务器配置

## 部署策略

### 静态部署
- **GitHub Pages**: 简单的静态页面托管
- **Vercel**: 自动化的现代部署平台
- **Netlify**: 一体化部署和性能优化

### 服务配置
- **路由重写**: 确保 SPA 路由正常工作
- **安全头**: 设置适当的安全头
- **性能头**: 优化加载性能

## 环境变量

### 部署相关变量
- `VITE_APP_BASE_URL`: 应用基础 URL
- `VITE_API_BASE_URL`: API 服务地址
- `VITE_SENTRY_DSN`: 错误监控服务地址

### 性能监控
- 页面加载时间

- 错误率监控

### 运维配置
- 健康检查端点
