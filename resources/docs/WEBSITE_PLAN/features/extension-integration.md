# 扩展集成机制

## Eagle 与 AE 扩展通信

### 通信协议
- **消息格式**: 定义标准的消息数据结构
- **事件系统**: 基于事件的异步通信机制
- **错误处理**: 完善的错误处理和重试机制

### API 接口
- **导入接口**: 从 Eagle 向 AE 导入资源
- **导出接口**: 从 AE 向 Eagle 导出资源
- **状态同步**: 扩展间的状态同步机制

## 预设管理

### 预设存储
- **本地存储**: 在用户设备上存储预设
- **云端同步**: 可选的云端预设同步功能
- **版本控制**: 预设的版本管理和回滚

### 预设格式
- **配置文件**: JSON 格式的预设配置
- **元数据**: 包含创建时间、修改时间等元数据
- **导入导出**: 预设的导入导出功能

## 拖拽导入功能

### 拖拽协议
- **文件格式支持**: 支持多种媒体文件格式
- **拖拽源**: 支持从 Eagle、本地文件系统等来源
- **拖拽目标**: 在 AE 界面内的拖拽区域

### 性能优化
- **批量处理**: 支持批量文件拖拽导入
- **进度显示**: 导入进度的实时反馈
- **错误恢复**: 导入失败时的恢复机制

## 导入模式

### 模式类型
- **直接链接**: 文件保持原位置，只创建链接
- **复制到项目**: 将文件复制到项目文件夹
- **指定位置**: 将文件复制到用户指定位置

### 模式选择
- **用户配置**: 用户可自定义默认导入模式
- **智能推荐**: 根据文件类型和使用场景推荐模式
- **项目设置**: 基于项目需求的模式选择

## 导入行为控制

### 行为选项
- **自动添加**: 自动将导入文件添加到时间轴
- **仅入库**: 仅将文件添加到项目面板
- **预合成创建**: 创建预合成以保持组织性

### 智能行为
- **格式适配**: 根据文件格式选择最佳行为
- **项目上下文**: 根据当前项目状态调整行为
- **用户偏好**: 基于用户历史操作的智能推荐

## 导出功能

### 导出选项
- **图层导出**: 将 AE 图层导出为图片文件
- **格式选择**: 支持多种导出格式
- **质量控制**: 可配置的导出质量设置

### 导出优化
- **批量导出**: 支持批量图层导出
- **进度监控**: 导出进度的实时监控
- **自动归档**: 导出后自动归档到 Eagle

## 格式支持

### 支持的格式
- **图像格式**: PNG, JPEG, GIF, SVG, WebP 等
- **视频格式**: MP4, MOV, AVI, MKV 等
- **音频格式**: MP3, WAV, AAC 等
- **其他格式**: 特定工作流程所需格式

### 格式处理
- **元数据保留**: 保留原始文件的元数据
- **压缩优化**: 针对不同格式的压缩优化
- **质量平衡**: 在文件大小和质量间平衡
