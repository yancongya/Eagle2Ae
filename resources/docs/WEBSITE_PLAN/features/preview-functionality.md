# 预览功能详解

## 预览系统架构

### Splitpanes 集成
使用 Splitpanes 组件实现多视图预览功能：

```vue
<template>
  <Splitpanes class="default-theme">
    <Pane :min-size="20" :size="50">
      <iframe src="/extensions/ae/preview.html" />
    </Pane>
    <Pane :min-size="20" :size="50">
      <iframe src="/extensions/eagle/preview.html" />
    </Pane>
  </Splitpanes>
</template>
```

### 响应式布局
- **单面板模式**: 移动设备上单面板显示
- **双面板模式**: 桌面设备上双面板对比
- **多面板模式**: 大屏设备上的多面板布局
