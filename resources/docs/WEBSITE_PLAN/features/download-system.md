## 安装指导

### AE 扩展安装
```markdown
1. 下载 .zxp 文件
2. 使用 Extension Manager 安装
3. 或使用 ZXPInstaller 工具
4. 重启 After Effects
5. 在窗口菜单中找到扩展
```

### Eagle 扩展安装
```markdown
1. 下载插件文件
2. 在 Eagle 中打开插件管理
3. 安装下载的插件
4. 重启 Eagle 应用
5. 验证插件正常运行
```
