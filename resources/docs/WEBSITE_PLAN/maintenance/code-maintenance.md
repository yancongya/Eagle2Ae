# 代码维护指南

## 代码规范

### 编码标准
- **ESLint**: 使用 ESLint 确保代码风格一致
- **Prettier**: 使用 Prettier 自动格式化代码
- **Vue 3 最佳实践**: 遵循 Vue 3 的最佳实践
- **Composition API**: 优先使用 Composition API

### 命名约定
- **组件命名**: 使用 PascalCase 命名 Vue 组件
- **文件命名**: 使用 kebab-case 命名文件
- **变量命名**: 使用 camelCase 命名变量和函数
- **常量命名**: 使用 UPPER_SNAKE_CASE 命名常量

## 代码结构

### 目录结构
```
src/
├── components/     # 可复用的 Vue 组件
├── views/         # 页面级组件
├── composables/   # Vue Composition 函数
├── utils/         # 工具函数
├── assets/        # 静态资源
├── styles/        # 全局样式
├── locales/       # 国际化文件
└── router/        # 路由配置
```

### 组件结构
- **单一职责**: 每个组件只负责单一功能
- **可复用性**: 设计可复用的组件
- **可维护性**: 保持组件的可维护性
