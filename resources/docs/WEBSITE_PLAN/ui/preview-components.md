# 预览组件

## 组件概述

预览组件使用 Splitpanes 组件实现多视图预览功能，主要用于展示 Eagle 和 AE 扩展的界面预览。

## Splitpanes 集成

### 基本配置
```vue
<template>
  <Splitpanes class="default-theme preview-container">
    <Pane :min-size="20" :size="50" class="preview-pane">
      <iframe 
        :src="aePreviewUrl" 
        class="preview-iframe"
        title="AE 扩展预览"
        frameborder="0"
      />
    </Pane>
    <Pane :min-size="20" :size="50" class="preview-pane">
      <iframe 
        :src="eaglePreviewUrl" 
        class="preview-iframe"
        title="Eagle 扩展预览"
        frameborder="0"
      />
    </Pane>
  </Splitpanes>
</template>
```

### 组件特性
- **可调整大小**: 用户可拖拽调整面板大小
- **最小尺寸**: 设置面板最小尺寸限制
- **主题定制**: 使用默认主题并可自定义
- **响应式**: 适配不同屏幕尺寸
