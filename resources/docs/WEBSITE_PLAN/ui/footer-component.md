# 页脚组件

## 组件概述

页脚组件位于页面底部，提供版权信息、联系方式和相关链接，是网站的重要组成部分。

## 组件结构

### 基本布局
```vue
<template>
  <footer class="site-footer">
    <div class="footer-content">
      <div class="footer-section">
        <h4 class="footer-title">{{ t('footer.links') }}</h4>
        <ul class="footer-links">
          <li><a :href="docsLink" target="_blank">{{ t('nav.docs') }}</a></li>
          <li><a :href="githubLink" target="_blank">{{ t('footer.github') }}</a></li>
          <li><a :href="feedbackLink" target="_blank">{{ t('footer.feedback') }}</a></li>
        </ul>
      </div>
      <div class="footer-section">
        <p class="copyright">{{ t('footer.copyright') }}</p>
      </div>
    </div>
  </footer>
</template>
```

### 组件层级
- **容器层**: footer 根元素，包含所有页脚内容
- **内容层**: 页脚内容的主要容器
- **分区层**: 不同功能区的分组容器
- **元素层**: 具体的文本、链接、图片等元素

## 内容组成

### 版权信息
- **版权声明**: 明确的版权归属信息
- **年份标识**: 自动更新的版权年份

### 导航链接
- **文档链接**: 指向相关文档的链接

### 联系信息
- **社交媒体**: 相关社交媒体链接
- **联系方式**: 官方联系方式
- **帮助中心**: 帮助和支持信息

## 技术实现

### Vue 组件实现
```javascript
import { useI18n } from 'vue-i18n'

export default {
  setup() {
    const { t } = useI18n()
    
    const docsLink = t('links.docs')
    const githubLink = 'https://github.com/your-repo'
    const feedbackLink = 'mailto:feedback@example.com'
    
    return {
      t,
      docsLink,
      githubLink,
      feedbackLink
    }
  }
}
```
