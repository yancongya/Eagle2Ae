# 本地化指南

## 本地化策略

### 多语言支持
项目采用多语言支持策略，通过 vue-i18n 实现国际化和本地化功能。

## 语言资源管理

### 消息文件结构
```json
{
  "nav": {
    "home": "首页",
    "aePreview": "AE 预览", 
    "eaglePreview": "Eagle 预览",
    "download": "下载",
    "about": "关于",
    "docs": "使用文档"
  },
  "home": {
    "title": "Eagle 与 AE 的无缝桥梁",
    "features": {
      "dragDrop": {
        "title": "拖拽导入",
        "desc": [
          "从 Eagle 直接拖拽素材到 AE",
          "支持多种文件格式"
        ]
      }
    }
  }
}
```

### 文件组织
- **按语言组织**: 每种语言一个独立的 JSON 文件
- **按功能分组**: 消息按功能模块分组
- **嵌套结构**: 使用嵌套结构组织相关消息

## 本地化实现

### 消息键命名规范
- **模块前缀**: 使用模块名称作为键的前缀
- **功能细分**: 按功能细分消息键
- **描述性命名**: 使用描述性的命名方式

### 动态内容
```javascript
// 处理动态内容
const welcomeMessage = t('messages.welcome', { name: userName });

// 处理复数形式
const itemCount = t('messages.items', { count: items.length }, items.length);
```

## 文本本地化

### 静态文本
- **模板中使用**: 在 Vue 模板中使用 t() 函数
- **脚本中使用**: 在 JavaScript 中使用 t() 函数
- **计算属性**: 在计算属性中使用国际化

### 动态文本
- **参数化消息**: 使用参数化消息处理动态内容
- **复数处理**: 正确处理复数形式
- **格式化**: 日期、数字等的本地化格式化

## 界面本地化

### 布局适配
- **文字长度**: 考虑不同语言文字长度差异
- **阅读方向**: 支持从右到左的语言（如需要）
- **字体选择**: 选择支持本地化字符的字体

### 文化适应
- **日期时间**: 不同文化背景下的日期时间格式
- **数字格式**: 数字分隔符和格式差异
- **货币符号**: 如涉及，正确显示当地货币

## 本地化工作流程

### 翻译流程
1. **内容提取**: 从代码中提取需要翻译的内容
2. **翻译执行**: 翻译到目标语言
3. **质量检查**: 检查翻译的准确性和一致性
4. **集成测试**: 测试翻译在界面中的显示

### 更新维护
- **新增内容**: 为新增内容添加多语言支持
- **修改维护**: 更新已存在的翻译内容
- **版本同步**: 确保翻译与功能版本同步

## 性能考虑

### 按需加载
- **懒加载**: 按需加载语言包
- **分割策略**: 合理分割语言资源
- **缓存机制**: 有效缓存翻译资源

### 优化策略
- **最小化**: 最小化语言包大小
- **预加载**: 预加载主要语言包
- **压缩**: 压缩语言资源文件

## 测试策略

### 翻译验证
- **内容完整性**: 验证所有文本都有对应翻译
