# 下载页面设计文档

## 概述

下载页面为用户提供 AE 和 Eagle 扩展的下载功能，采用现代化设计风格，具有良好的用户体验和视觉效果。

## 设计特点

### 1. 响应式布局
- 使用 CSS Grid 和 Flexbox 实现响应式设计
- 在移动设备上自动调整为单列布局
- 在桌面设备上显示为双列布局

### 2. 视觉设计
- 渐变背景色提升视觉层次
- 卡片式设计，带有阴影和圆角效果
- 悬停时的动画效果增强交互体验
- 深色模式支持

### 3. 色彩方案
- **AE 扩展**: 紫色到靛蓝色渐变 (purple-500 to indigo-600)
- **Eagle 扩展**: 青色到蓝色渐变 (cyan-500 to blue-500)
- **功能列表**: 绿色检查图标 (green-500)
- **安装指南**: 蓝色编号背景 (blue-100/900)

## 组件结构

### 1. 页面标题区域
- 主标题："获取扩展"
- 副标题：描述扩展功能的简短说明

### 2. 扩展下载卡片 (双列布局)
#### AE 扩展卡片
- 紫色渐变边框
- AE 字母标识
- 功能列表：
  - 从 Eagle 直接导入素材到 AE
  - 支持多种素材格式批量处理
  - 实时预览素材效果
  - 自动素材分类到对应文件夹
- 下载按钮

#### Eagle 扩展卡片
- 青色渐变边框
- E 字母标识
- 功能列表：
  - 与 AE 扩展实时通信
  - 同步素材状态更新
  - 自动整理项目文件
  - 智能文件夹管理
- 下载按钮

### 3. 安装指南区域
- 三步安装指南：
  1. 下载扩展
  2. 安装扩展
  3. 开始使用
- 每步都有图标和说明文字

## 交互功能

### 1. 下载按钮交互
- 点击下载按钮触发 `downloadExtension` 函数
- 显示下载提示信息
- 可扩展为实际下载功能

### 2. 悬停效果
- 卡片悬停时阴影加深并轻微上移
- 按钮悬停时颜色变化并轻微放大
- 平滑的过渡动画

### 3. 深色模式支持
- 自动适配系统深色模式偏好
- 深色模式下使用深色背景和亮色文字
- 保持一致的视觉效果

## 技术实现

### 1. Vue 3 Composition API
- 使用 `<script setup>` 语法糖
- 使用 `ref` 响应式数据
- 事件处理函数

### 2. Tailwind CSS
- 使用实用类实现样式
- 响应式断点 (sm, md, lg)
- 深色模式类 (dark:)

### 3. SVG 图标
- 使用内联 SVG 图标
- 检查标记图标
- 下载箭头图标
