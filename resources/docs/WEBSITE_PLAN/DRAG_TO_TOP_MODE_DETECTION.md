# DragToTop 组件优化文档

## 模式判定优化

### 优化概述
在之前版本中，组件可能存在拖拽过程中模式切换不稳定的问题。本次优化重新设计了模式判定逻辑，确保在鼠标按下那一刻就确定是拖拽模式还是选择模式。

### 模式判定逻辑

#### 1. 模式确定时机
- 在鼠标按下时 (`handleMouseDown`) 就确定操作模式
- 如果按下时在空区域，则进入拖拽模式
- 如果按下时在元素上，则进入选择模式（允许浏览器默认行为）

#### 2. 模式稳定性
- 一旦进入拖拽模式，在整个拖拽过程中保持状态不变
- 避免拖拽过程中模式的不稳定切换
- 在拖拽过程中光标固定为 `grabbing`

### 光标管理优化

#### 1. 光标更新时机
- 只在关键节点更新光标：mouseenter, mouseleave, mousedown, mouseup
- 移除 mousemove 事件中的光标更新逻辑以避免闪烁
- 在非拖拽状态下才更新光标样式

#### 2. 光标状态
- 空区域：`grab` 光标
- 拖拽中：`grabbing` 光标
- 有元素或选择模式：默认光标

### 交互行为

#### 1. 拖拽模式
- 在空区域点击并拖拽
- 显示连接线和logo动画
- 拖拽距离超过阈值时执行相应动作
- 在Hero区域拖拽则刷新页面
- 在其他区域拖拽则滚动到顶部

#### 2. 选择模式
- 在交互元素（按钮、链接等）上点击
- 不干扰浏览器默认的选择行为
- 允许文本选择等操作

### 性能改进

- 移除可能导致闪烁的防抖机制
- 简化的事件处理逻辑
- 更加稳定的用户体验

### 技术实现

#### 1. 检测逻辑
- 使用 `document.elementsFromPoint` 检测鼠标下的元素
- 重点关注交互性元素（BUTTON, A, INPUT等）
- 检查CSS光标样式和事件属性

#### 2. 事件处理
- `handleMouseDown`：确定模式并初始化
- `handleMouseMove`：仅处理拖拽中的位置更新
- `handleMouseUp`：完成拖拽并重新评估光标状态
- `handleMouseEnter/Leave`：管理区域进入/离开的光标状态

### 用户体验提升

- 消除了拖拽过程中的闪烁问题
- 更稳定的操作模式
- 更清晰的视觉反馈
- 更流畅的交互体验
