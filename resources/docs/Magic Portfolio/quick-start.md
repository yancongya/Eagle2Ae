# Magic Portfolio - 快速开始

**最后更新：2025年3月16日**

---

### 关于

Magic Portfolio 是一个全面的、基于 MDX、对SEO友好、响应式的作品集模板，使用 Once UI 和 Next.js 构建。

---

### 许可证

Magic Portfolio 在 CC BY-NC 4.0 许可下授权。您只能将其用于个人目的，并且必须署名原作品。署名默认添加在页脚，但您可以将其放置在网站的任何其他可见部分。

订阅 Once UI Pro 计划可将许可证扩展到 Dopler CC。

---

### 快速开始

克隆 git 仓库：
```shell
git clone https://github.com/once-ui-system/magic-portfolio.git
```

安装必要的依赖项：
```shell
npm install
```

启动本地开发服务器：
```shell
npm run dev
```
