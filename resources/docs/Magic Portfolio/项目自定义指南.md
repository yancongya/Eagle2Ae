# Magic Portfolio 项目文件自定义指南

本指南将详细说明 `magic-portfolio` 项目中各个文件和文件夹的用途，以及如何进行自定义修改。

---

## 1. 根目录文件 (Root Directory Files)

这些文件位于项目的最顶层，主要负责整个项目的配置、依赖和脚本。

- `package.json`: 项目的核心清单，定义了依赖库和可运行脚本（如 `pnpm dev`）。通常无需修改。
- `next.config.mjs`: Next.js 框架的主要配置文件。如果您想从新的外部域名加载图片，需要在此文件的 `images.remotePatterns` 中添加配置。
- `tsconfig.json`: TypeScript 配置文件，定义了路径别名（如 `@/*` 指向 `src/*`）等规则。常规修改无需触碰。
- `.env.example`: 环境变量的**示例文件**。如需设置密码保护等功能，应复制此文件为 `.env.local` 并在其中填入您的密码。
- `.eslintrc.json`, `biome.json`, `.lintstagedrc.js`: 代码质量和格式化工具的配置文件，不影响网站内容。
- `.gitignore`: 告诉 Git 哪些文件（如 `node_modules`）不需要被版本控制。

---

## 2. public 目录 (Public Directory)

这个文件夹是您网站的“静态资源库”，所有内容都可以通过域名直接访问。

- **修改方法**: 直接替换或添加文件。
- **`images/`**: **(重要)** 存放核心图片的地方。
  - `avatar.gif` / `avatar.jpg`: 您的**个人头像**。
  - `gallery/`: `/gallery` 页面的图片。
  - `og/`: 社交媒体分享的**预览图**。
  - `projects/`: “作品(Work)”的图片。
- `trademarks/`: 存放商标/Logo图片。
- `ae/`, `eagle/`: 为对应页面预留的静态资源目录。

---

## 3. src 目录 (Source Directory)

这是您项目的**核心代码文件夹**。

### `src/app/` - 页面路由中心

此目录的结构直接决定了网站的URL。

- `layout.tsx`: **网站主模板**，包含所有页面共享的页眉、页脚和全局样式。
- `page.tsx`: **网站主页** (`/` 路径)。
- `not-found.tsx`: 自定义的 **404 页面**。
- `about/`, `work/`, `blog/`, `gallery/`: 分别对应网站的 `/about`, `/work` 等页面，其下的 `page.tsx` 负责渲染该页面。
- `[extensionName]/`: **动态路由**文件夹，可匹配 `/ae`, `/eagle` 等路径。
- `api/`: **后端API路由**，用于处理服务器端逻辑。

### `src/components/` - 可复用UI组件

构成您网站页面的“积木块”。

- `Header.tsx` / `Footer.tsx`: 网站的**页眉**和**页脚**。
- `Providers.tsx`: **全局供给组件**，提供主题（明暗模式）和图标库等全局功能。
- `RouteGuard.tsx`: **路由守卫**，处理密码保护逻辑。
- `mdx.tsx`: **MDX渲染器配置**，定义 `.mdx` 文章内容的渲染方式。
- `ThemeToggle.tsx`: 主题切换按钮。
- `ProjectCard.tsx`: 单个项目预览卡片。

### 其他 `src` 目录

- `resources/`: **(数据大脑)** **自定义最频繁的目录**。包含 `content.tsx` (文本内容), `once-ui.config.ts` (样式/路由配置), `icons.ts` (图标注册)。
- `types/`: **类型定义**，用于保证代码健壮性，通常无需修改。
- `utils/`: **工具函数**，存放通用的辅助函数。
