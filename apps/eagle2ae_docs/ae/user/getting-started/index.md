### 核心概念

了解插件的基本概念，帮助您更好地使用各项功能：

- **导入模式** - 决定文件是直接链接还是复制到项目旁边/指定文件夹
- **导入行为** - 决定素材是否以及如何被添加到当前合成中
- **项目状态检测** - 确保操作的安全性和准确性
- **多面板支持** - 支持同时打开多个扩展面板实例

## 🎯 功能概览

### 核心导入功能

Eagle2Ae AE 扩展提供了多种便捷的导入方式：

1. **拖拽导入** - 从桌面或文件夹直接拖拽文件到扩展面板
2. **剪贴板导入** - 从剪贴板粘贴图片到扩展面板
3. **Eagle 导入** - 从 Eagle 素材库拖拽素材到扩展面板

### 主要特性

- **极速连接** - 连接延迟优化至300ms以内
- **智能通知** - Eagle通知系统，连接状态实时反馈
- **资源库监控** - 自动检测资源库变化
- **多面板支持** - 每个面板拥有独立的预设文件
- **UI 控制系统** - 主题切换、语言切换、组件显示控制

## 💡 最佳实践

### 工作流程优化

1. **合理组织文件夹结构** - 便于批量导入
2. **使用有意义的文件名** - 便于后续查找
3. **定期备份预设文件** - 防止配置丢失
4. **合理使用缓存机制** - 避免重复检测

### 安全使用建议

1. **优先使用"项目旁复制"模式** - 确保项目可移植性
2. **定期检查项目状态** - 使用项目状态检测器
3. **注意文件路径** - 避免使用特殊字符
4. **及时更新插件** - 获得最新功能和修复
