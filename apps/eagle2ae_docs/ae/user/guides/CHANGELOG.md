# 更新日志 (Changelog)

## v2.4.0 (2025年9月)

### 🚀 新功能

- **多面板支持**
  - 实现了一个扩展支持多个面板实例同时打开的功能
  - 每个面板拥有独立的预设文件，支持个性化配置
  - 添加了面板ID识别机制，确保各面板配置互不干扰

- **UI 控制系统**
  - 新增了完整的UI控制功能，可自定义主面板各组件显示/隐藏
  - 实现了主题切换功能，支持暗色和亮色模式
  - 添加了语言切换功能，支持中英文动态切换
  - 提供了独显模式（专注模式），可最大化显示特定功能区域

- **拖拽导入增强**
  - 添加了文件夹拖拽支持，可直接将整个文件夹导入到After Effects
  - 实现了序列帧自动检测功能，能够识别图片序列并将其作为单个序列导入
  - 添加了项目内文件检测，防止重复导入已在项目中的文件
  - 增强了拖拽视觉反馈，提供实时状态提示

- **剪贴板导入优化**
  - 实现了剪贴板图片自动检测和导入功能
  - 添加了临时文件智能重命名，避免使用通用名称如"clipboard_image.png"
  - 优化了剪贴板导入确认对话框，提供更好的用户体验

- **项目状态检测器**
  - 新增了全面的项目状态检测系统，确保操作的安全性和准确性
  - 实现了环境检测、AE连接检测、项目状态检测、合成状态检测和Eagle连接检测
  - 添加了缓存机制，提高检测效率

- **虚拟对话框系统**
  - 为演示模式添加了虚拟对话框系统，提供一致的用户体验
  - 实现了模拟用户选择功能，用于演示模式下的交互

### 🛠️ 改进

- **UI/UX 优化**
  - 重新设计了快速设置面板，提供更直观的操作体验
  - 改进了导入模式和行为设置，支持更多自定义选项
  - 优化了状态显示和连接指示器，提供更清晰的视觉反馈
  - 添加了主题切换功能，支持暗色和亮色模式
  - 实现了语言动态切换，无需重启即可切换界面语言

- **设置管理增强**
  - 实现了面板特定的设置管理，支持多个面板实例独立配置
  - 添加了预设文件管理功能，支持导出和导入配置
  - 增强了自动保存功能，确保设置变更及时保存
  - 实现了UI组件显示控制，可自定义面板布局

- **日志系统改进**
  - 重新设计了日志显示系统，支持AE扩展日志和Eagle插件日志分离显示
  - 添加了重复日志合并功能，减少日志冗余
  - 优化了日志性能，提高大型项目的响应速度

- **通信系统优化**
  - 改进了WebSocket和HTTP通信机制，提供更稳定的连接
  - 添加了端口自动发现功能，简化配置过程
  - 增强了错误处理和重连机制

### 🐛 修复

- 修复了在某些系统上无法正确获取AE版本的问题
- 解决了项目状态检测在复杂项目结构下的准确性问题
- 修复了拖拽导入时文件路径解析的错误
- 解决了剪贴板导入在高DPI显示器上的兼容性问题
- 修复了多面板实例间的配置冲突问题

- **UI/UX 改进**
  - 重新设计了主界面布局，提供更清晰的信息展示
  - 改进了响应式设计，适配不同屏幕尺寸
  - 优化了动画效果，提供更流畅的用户体验

### 🐛 修复

- 修复了在macOS上某些版本的兼容性问题
- 解决了项目文件路径包含特殊字符时的处理错误
