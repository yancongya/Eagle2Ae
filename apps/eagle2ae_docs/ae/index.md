## 🚀 新功能概览 (v2.5.0)

### 导入行为选项优化

- **4个独立选项** - 不导入合成、创建预合成、当前时间、时间轴开始
- **直观交互** - 无需二次点击，直接选择任意选项
- **简化逻辑** - 去除复杂的子模式切换机制

### 控制台日志简化

- **减少80%日志输出** - 将详细日志改为debug级别
- **优化开发体验** - 保留错误、警告和用户操作日志
- **提升调试效率** - 日志信息更聚焦

### 性能优化

- **减少200行代码** - 删除复杂的子模式切换代码
- **降低5%内存占用** - 代码执行路径更简洁
- **提升维护性** - 代码逻辑更清晰易维护
