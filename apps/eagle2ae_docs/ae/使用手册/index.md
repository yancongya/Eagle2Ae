## 🚀 功能概览

### 核心导入功能
Eagle2Ae AE 扩展提供了多种便捷的导入方式：

1. **拖拽导入** - 从桌面或文件夹直接拖拽文件到扩展面板
2. **剪贴板导入** - 从剪贴板粘贴图片到扩展面板
3. **Eagle 导入** - 从 Eagle 素材库拖拽素材到扩展面板

### 导入模式选择
- **直接导入** - 直接链接到素材的原始路径，不复制文件
- **项目旁复制** - 将素材文件复制到当前AE项目文件旁边后导入
- **指定文件夹** - 将素材文件复制到用户指定的文件夹后导入

### 导入行为设置
- **不导入合成** - 只将素材导入到项目面板，不添加到时间轴
- **当前时间** - 将素材添加到时间轴的当前时间指针位置
- **时间轴开始** - 将素材移至时间轴开始处（0秒位置）

### 导出功能
- **图层检测** - 检测当前合成中的图层
- **图层导出** - 将选中的图层导出为图片
- **导出到 Eagle** - 将导出的图片自动归档到 Eagle 素材库
